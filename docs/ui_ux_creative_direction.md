# **AETHEX – Complete UI/UX Creative Direction**

## 1. Project Mission
You are a Senior Creative Director, Awwwards-winning UI/UX Designer, Brand Designer, and Frontend Architect.
Your task is to completely redesign the existing AETHEX application into a world-class premium sneaker experience.
* This is **NOT** an e-commerce template.
* This is **NOT** a Shopify theme.
* This is **NOT** a dashboard.
* This is a cinematic luxury digital fashion experience inspired by modern product storytelling.
* The final result should be worthy of submission to Awwwards, CSS Design Awards, and FWA.
* Everything must feel handcrafted, premium, editorial, and immersive.

---

## 2. Design Philosophy
* **Keywords:** Luxury, Minimal, Editorial, Cinematic, Architectural, Timeless, Monochrome, Museum, Gallery, Fashion, Technology, Emotion, Negative Space, Premium Materials, Product First.
* The sneaker is always the hero.
* The interface must disappear.
* Content must breathe.
* Every section should feel like a premium fashion campaign.

---

## 3. Visual Style

### Theme
* Black & White only.
* No colorful gradients.
* No neon.
* No glassmorphism.
* No cyberpunk.
* No glowing UI.
* Only luxury monochrome.

### Color Palette
* **Background:** Black `#050505`
* **Surface:** `#0B0B0B`
* **Cards:** `#111111`
* **Borders:** `rgba(255,255,255,0.08)`
* **Primary Text:** White `#FFFFFF`
* **Secondary Text:** `#9A9A9A`
* **Muted:** `#6B6B6B`
* **Hover:** `#ECECEC`
* **Accent:** Only use white. No other accent colors.

---

## 4. Typography
Typography should feel like a luxury fashion magazine.

* **Primary Font:** Neue Montreal (Alternative: Satoshi, General Sans)
* **Body Font:** Inter
* **Numbers:** Space Grotesk
* **Hierarchy:**
  * **Hero:** `96–140px`
  * **Section Title:** `72px`
  * **Product Title:** `48px`
  * **Heading:** `32px`
  * **Body:** `18px`
  * **Caption:** `13px`
* Use generous letter spacing. Very clean alignment. Large margins. Editorial composition.

---

## 5. Grid System
Use a 12-column responsive grid.
* **Desktop Maximum Width:** `1600px`
* Large whitespace. Do not center everything. Use asymmetrical layouts. Allow images to bleed off the screen.

---

## 6. Spacing System
Whitespace is luxury.
* **Base Spacing:** `8px`
* **Allowed Values:** `8`, `16`, `24`, `32`, `48`, `64`, `96`, `128`, `160`
* Never crowd elements.

---

## 7. UI Language
* No rounded modern SaaS cards.
* No colorful buttons.
* No shadows everywhere.
* No gradients.
* No floating glass panels.
* **Instead use:** Hairline borders, Thin typography, Massive imagery, Editorial alignment, Museum-style labels, Invisible containers.
* Sections should feel like pages in a fashion magazine.

---

## 8. Buttons
* **Primary:** Solid white, Black text, Large padding, Minimal border radius.
* **Secondary:** Transparent, Hairline border, Underline hover animation.
* **Micro interaction:** Buttons should feel expensive.

---

## 9. Icons
* Lucide, Thin stroke, `24px`. No filled icons.

---

## 10. Imagery
Only use:
* Studio photography
* Luxury lighting
* Macro material photography
* Editorial photography
* Architectural compositions
* No generic e-commerce mockups. No stock backgrounds.

---

## 11. Motion Design
Everything should move like a camera. Never like an app.
* **Motion Principles:** Slow, Heavy, Elegant, Organic, Camera-based.
* **Use:** Framer Motion, Scroll transforms, Opacity, Scale, Rotate, Blur, Parallax.
* **Never animate:** `top`, `left`, `width`, `height`. Only GPU transforms.

---

## 12. Cursor
* Custom cursor, Magnetic buttons, Image reveal hover, Text distortion hover, Luxury interactions.

---

## 13. Navigation
Hidden until needed. Minimal.
* **Structure:** Logo, Collections, Drops, Archive, Journal, Cart.
* Menu animation should slide like an editorial panel.

---

## 14. Page Structure

### Home
Hero ➔ Featured Drop ➔ Brand Philosophy ➔ Collection Preview ➔ Material Story ➔ Editorial Gallery ➔ Latest Drops ➔ Newsletter ➔ Footer

### Collection Page
Minimal introduction ➔ Large editorial typography ➔ Massive product imagery ➔ Very little UI ➔ Products displayed as gallery pieces (not e-commerce cards) ➔ Hover reveals product information ➔ Smooth transitions.

### Product Page
Scene 1: Hero Sneaker ➔ Scene 2: Origin Story ➔ Scene 3: Material Macro ➔ Scene 4: 360 Showcase ➔ Scene 5: Technical Details ➔ Scene 6: Lifestyle Campaign ➔ Scene 7: Size Selection ➔ Scene 8: Acquire Drop.
* No sidebar. No traditional product layout. The experience should feel like walking through an exhibition.

### About Page
Brand film ➔ Mission ➔ Craftsmanship ➔ Materials ➔ Studio ➔ Timeline.
* Large editorial photography.

### Journal
* Luxury editorial blog. Large covers. Minimal typography. Magazine layout.

### Archive
* Previous drops. Timeline layout. Very minimal. Museum archive feeling.

### Cart
* Extremely minimal. Floating drawer. Large typography. Very clean. No clutter.

### Checkout
* Calm. Minimal. Apple-level checkout experience. Nothing distracting.
